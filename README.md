# AI Scheme Assist

AI-powered welfare scheme eligibility and assistance platform.

## Overview

AI Scheme Assist helps users discover welfare schemes, understand eligibility requirements, verify necessary information, and access relevant application services.

## Features

- User authentication
- Welfare scheme discovery
- Eligibility checking
- Aadhaar verification workflow
- DigiLocker integration workflow
- Document management
- AI-assisted scheme assistance
- Backend API services

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- Express
- MongoDB
- Google Gemini
